# InkGuard AI

AI-powered content creation platform with built-in safety — writing tools protected by real-time plagiarism, brand voice, and prompt-injection detection, powered by IBM Granite via watsonx.ai.

## The Issue

Content creators, marketers, and businesses today rely heavily on AI writing tools to produce emails, blogs, presentations, and creative content at speed — but this speed comes with hidden risks. AI-generated text can unknowingly contain plagiarized material, off-brand tone, or factually risky claims, while malicious prompt injection attacks can quietly compromise AI systems without users ever noticing.

Existing AI writing platforms focus purely on content generation and treat safety as an afterthought — leaving creators to manually check grammar, originality, brand consistency, and security risks across separate, disconnected tools, with no single system giving a clear risk picture before content goes live.

## Our Magic Solution

InkGuard AI unifies AI-powered content creation and content safety into a single, seamless platform. Every piece of content — whether generated by our AI Writer, Blog Writer, Email Writer, CV Generator, or PPT Generator — passes automatically through a real-time Safety Layer powered by IBM Granite via watsonx.ai, which checks grammar, spelling, plagiarism, brand voice alignment, and AI-vs-human content detection.

A dedicated Prompt Scanner screens every input for injection attacks before it ever reaches the model, while the Risk Score engine aggregates all these signals into one clear, overall safety rating creators can trust at a glance. Every analysis — passed or flagged — is logged in a full Audit Log, giving teams complete transparency and traceability.

Where most AI writing tools stop at generation and leave safety checking to separate, disconnected services, InkGuard AI runs generation and safety review in the same pass — turning a multi-tool, multi-tab workflow into a single dashboard action that returns a ready-to-publish result with its risk rating attached, typically in a few seconds per check rather than the minutes it takes to run the same content through several standalone checkers.

Beyond the platform itself, we've built and open-sourced a range of websites under the InkGuard AI umbrella — including this platform itself, live at `ink.freedev.app` — made freely available for students to test, explore, and learn from — no strings attached. It's not about profit or recognition; it's about making technology genuinely accessible, so that anyone, regardless of technical background, can pick it up and use it with ease.

The result is a complete content workflow — generate, detect, verify, and humanize — all in one dashboard, built to be as effortless for a first-time user as it is powerful for a professional team.

## AI Approach & Architecture

InkGuard AI is a standalone PHP web application built around **IBM Granite via watsonx.ai** as its core AI engine, with **Stable Diffusion (via Hugging Face)** as a secondary service for image-based tools.

**Data flow:**

```
User (Browser)
   │
   ▼
InkGuard AI — PHP Web App (Unified Dashboard)
   │
   ├──► OCR Input Layer (Tesseract.js) — for scanned/image text input
   │
   ├──► INK: Create & Produce
   │     AI Chat Assistant / Prompt Optimizer
   │        → AI Writer / Blog / Email / CV Generator
   │        → PPT Generator (OOXML)
   │        → Logo Generator / Text-to-Image
   │        → AI Humanizer
   │     (all call IBM Granite; image tools call Stable Diffusion)
   │
   └──► GUARD: Safety & Trust
         Spelling Checker → Grammar Checker → Plagiarism Checker
         → AI Content Detector → Brand Rules / Voice Checker
         → Prompt Injection Scanner → Risk Score Engine → Audit Log
         (all call IBM Granite)
   │
   ▼
Results → Dashboard (saved to Audit Log)
```

- **Core model:** IBM Granite, accessed via watsonx.ai API through PHP backend proxies, powers every safety check and content-generation task — grammar analysis, plagiarism detection, AI-vs-human classification, brand-voice alignment, and prompt-injection scanning all route through Granite model calls.
- **Image generation:** Stable Diffusion (via Hugging Face) is used as a secondary service for Logo Generator and Text-to-Image.
- **Generation layer (INK):** AI Writer, Blog Writer, Email Writer, CV Generator, and PPT Generator send structured prompts to Granite and return formatted output to the user.
- **Safety layer (GUARD):** Every generated or user-submitted piece of content is automatically passed through Grammar/Spelling/Plagiarism checks, Brand Voice comparison, and AI-vs-human Content Detection before being marked safe to use.
- **Security layer:** The Prompt Scanner inspects incoming prompts for injection-attack patterns *before* they reach the model, reducing the risk of prompt manipulation.
- **Risk Score engine:** Aggregates the results of all safety checks into a single, easy-to-read risk rating.
- **Audit Log:** Persists every analysis (passed or flagged) for transparency and traceability.
- **Data sources:** Unstructured — free text input, uploaded documents/images (OCR via Tesseract.js). Structured — risk scores, audit log entries, user-submitted forms (CV data, brand rules).
- **Modularity:** Each of the 20 tools is a self-contained module sharing a common PHP backend and authentication layer, so GUARD and INK tools can be combined in one workflow — e.g. generate a blog post with INK, then immediately run it through GUARD's plagiarism and AI-detector checks before publishing.
- **Backend:** PHP + MySQL, with a modular file-per-tool structure (e.g. `ai_writer.php`, `prompt_scanner.php`, `audit_log.php`) calling the watsonx.ai API.
- **Authentication:** Google OAuth login flow for user accounts.

## Impact

- Reduces the number of separate tools a student or creator needs from **5+ down to 1 dashboard**.
- Cuts content-review time by combining generation and verification into a single pass instead of sequential tool-switching across disconnected apps.
- Provides a quantifiable **Risk Score** so users get an objective originality/safety measure instead of guesswork.

**Scalability:** the modular architecture (20 independent tools sharing one backend) allows new checks or generators to be added without reworking the core system — able to scale from individual students to institutional use (schools/universities running bulk originality checks) or business teams needing brand-consistent content at volume.

**Beyond the demo:** InkGuard AI is already live and free for students to try at `ink.freedev.app`. Beyond the challenge, it can integrate with LMS platforms (Google Classroom, Moodle) for automatic assignment screening, or expose an API so other apps can plug in GUARD's trust-layer checks directly.

## Getting Started (Local Development)

1. Clone this repository into your local server's web root (e.g. XAMPP `htdocs`).
2. Import `inkguard_db.sql` into your MySQL server via phpMyAdmin.
3. Copy `.env.example` to `.env` and add your credentials:
   ```
   IBM_API_KEY=your_watsonx_api_key
   GOOGLE_CLIENT_ID=your_google_client_id
   DB_HOST=localhost
   DB_NAME=inkguard_db
   DB_USER=your_db_username
   DB_PASS=your_db_password
   ```
4. Update `config.php` to read these values via `getenv()`.
5. Visit `ink.freedev.app` in your browser.

> **Note:** Never commit `.env` or real API keys/passwords to this repository. Use environment variables or a `.gitignore`-protected config file.
